# **📌 TaskFlow – Full-Stack Task Manager (React, TailwindCSS, Appwrite)**

**TaskFlow** is a full-stack task management web application built with **React.js**, **TailwindCSS**, and **Appwrite**.  
It includes secure authentication, category-based task organization, and complete CRUD functionality.  
This project demonstrates real-world full-stack development skills with a clean UI and modern tooling.

---

## **🚀 Features**

### **🔐 Authentication**
- **User Registration & Login**
- **Secure Sessions** via Appwrite Auth  
- **Protected Routes**
- **User-Specific Data Isolation**

---

### **🗂️ Categories / Boards**
- Create new categories  
- Rename or delete categories  
- Each category contains its own set of tasks  

---

### **📝 Task Management**
- Add new tasks  
- Edit task title/description  
- Delete tasks  
- Mark tasks as **completed** or **pending**  
- **Priority levels**: Low / Medium / High  
- Optional **due dates**  
- Clean, responsive task cards  

---

### **📊 Dashboard Overview**
- Total number of tasks  
- Completed tasks  
- Pending tasks  
- Quick navigation to categories  

---

### **🎨 UI / UX**
- Built with **TailwindCSS**  
- Optional **Dark Mode**  
- Clean, minimal interface  

---

## **🛠️ Tech Stack**

### **Frontend**
- **React.js**
- **React Router**
- **TailwindCSS**

### **Backend**
- **Appwrite**
  - Authentication  
  - Database
